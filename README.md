# 🕌 AyahEar — Мобильное исламское приложение

> Кроссплатформенное мобильное приложение (iOS/Android) для мусульман с чтением Корана, **распознаванием сур по голосу через AI**, расчётом времени намаза, компасом Киблы, зикрами и дуа-дневником — на казахском, русском и английском языках.

## 🎯 Какую проблему решает

Существующие исламские приложения **не поддерживают казахский язык** или предлагают ограниченный функционал без интеграции современных AI-технологий. У мусульман Казахстана нет единого удобного мобильного приложения, которое бы объединяло основные инструменты поклонения и при этом работало на родном языке.

**AyahEar** решает эту проблему:

- 🎙 **AI-распознавание сур** — произнесите аят, и приложение определит суру через Google Speech-to-Text API и поиск по локальной базе Корана
- 🌐 **Полная поддержка казахского языка** — интерфейс, хиджра-календарь и названия месяцев на қазақша
- 📖 **Оффлайн-Коран** — полная база Корана хранится локально в SQLite (арабский текст + переводы на английский, русский и казахский)
- 🕐 **Точное время намаза** — расчёт по алгоритму PrayTimes.js с настройками для Алматы (метод Makkah/Umm Al-Qura)
- 🧭 **Компас Киблы** — определение направления на Каабу с использованием магнитометра и GPS
- ☁️ **Синхронизация** — прогресс чтения Корана и дуа сохраняются в Firebase Firestore между устройствами

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📖 **Коран** | Чтение всех 114 сур с арабским текстом, переводами; сохранение последней прочитанной суры |
| 🎙 **Распознавание сур** | Запись голоса → Google Speech-to-Text → нормализация арабского текста → поиск по базе аятов |
| 🕌 **Время намаза** | Расчёт 5 ежедневных молитв (Фаджр, Зухр, Аср, Магриб, Иша) + таймер до следующего намаза |
| 🧭 **Компас Киблы** | Анимированный компас с направлением на Каабу и расстоянием в километрах |
| 📿 **Зикры** | Счётчик зикров с сохранением прогресса в Firestore |
| 🤲 **Дуа-дневник** | Личный дневник дуа (CRUD) с синхронизацией через Firebase |
| 📛 **99 имён Аллаха** | Справочник из локальной базы данных |
| 🔐 **Авторизация** | Email-регистрация с подтверждением через Firebase Auth |
| 🔔 **Push-уведомления** | Firebase Cloud Messaging (FCM) с хранением токенов |
| 🗓 **Хиджра-календарь** | Отображение даты по исламскому календарю (казахский, русский, английский) |
| 🌍 **Мультиязычность** | Полная локализация на 3 языка (kk, ru, en) через i18next |

## 🚀 Как запустить

### Предварительные требования

- [Node.js](https://nodejs.org/) (v18+)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [Git](https://git-scm.com/)
- Мобильное устройство с приложением **Expo Go** или настроенный эмулятор (Android Studio / Xcode)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<your-username>/AAS-Diplom--TestALLtest.git
cd AAS-Diplom--TestALLtest/AAS-Diplom--TestALLtest
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Настроить Firebase

Проект уже содержит конфигурационные файлы Firebase:
- `google-services.json` — для Android
- `GoogleService-Info.plist` — для iOS

> ⚠️ Для работы со своим Firebase-проектом замените эти файлы на свои из [Firebase Console](https://console.firebase.google.com/).

### 4. Запустить приложение

```bash
# Запуск в режиме разработки
npx expo start

# Или напрямую на устройстве/эмуляторе
npx expo run:android
npx expo run:ios
```

### 5. Подключиться с телефона

1. Установите **Expo Go** из App Store / Google Play
2. Отсканируйте QR-код из терминала
3. Приложение откроется на вашем устройстве

> 💡 **Примечание:** Для работы распознавания сур по голосу и компаса Киблы необходимо физическое устройство (не эмулятор).
